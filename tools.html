🛠 ATTLOG Tools - AttendanceSuite v2.0.8 CVE-2023-3941

Tra log, đọc chấm công, chấm công thật ghi lên ATTLOG, xóa log, chỉnh thời gian
⚠️ Tool này khai thác CVE-2023-3941 (UPLOAD_PICTURE path traversal) trên ZK X628 PRO FW 6.60. Chỉ dùng trên thiết bị của bạn. Reboot thiết bị ~30s sau mỗi thao tác.

📡 1. Chọn thiết bị (chấm xanh = online)

📋 Hướng dẫn: Bấm 🔄 Refresh để quét 24 máy. Chấm xanh sáng = máy đang online (chấm được). Chấm đỏ = offline / tắt nguồn. Click vào máy muốn chấm.
Chưa quét. Bấm 🔄 Refresh.
💡 Chọn máy muốn chấm/xóa/sửa - cột "LAT" = latency (ms). <50ms = tốt, >200ms = mạng chậm.
🔍 Test PIN + Password (qua port 4370): kiểm tra user có tồn tại trên máy + so sánh password nếu có.

📥 2. Tra log / Đọc chấm công

📋 Hướng dẫn: Chọn số records muốn xem. Tool sẽ đọc từ web backup (nhanh ~5s) hoặc thiết bị (chậm ~25s cho 49k records).

✍️ 3. Chấm công thật (ghi ATTLOG lên máy)

📋 Workflow (4 bước, ~30-60s):
① Tải ZKDB.db từ web backup (auto-fallback: 172.16.254.202 → 172.16.200.105)
② Thêm 1 record ATTLOG mới (PIN + thời gian + marker)
③ Upload ZKDB.db lên máy qua CVE-2023-3941 (~3-4 phút, 32KB chunks)
④ Reboot máy (~30s downtime)

🎯 Marker (để quản lý records BS đã inject):
• APK_REAL_PUNCH → ghi qua mobile app (workflow thật)
• TEST_INJECT → test/dev thử nghiệm
• BS_CONFIRMED → BS verify thủ công, ATTLOG không thật trên máy nhưng tính như đã chấm

⚠️ Yêu cầu mạng: VPN Bệnh viện bật, có thể truy cập 172.16.x.x. Nếu fail → gợi ý bật VPN.

🧪 4. Inject tùy chỉnh (cho test / chấm hộ)

📋 Hướng dẫn: Điền PIN / thời gian / marker → bấm Inject. ⚠ Cẩn thận: upload lại toàn bộ ZKDB.db có thể mất record được chấm trong khoảng thời gian giữa web backup và upload (~1-2 phút).

🗑 5. Xóa log theo marker

📋 Hướng dẫn: Điền marker (vd: APK_REAL_PUNCH) → bấm Xóa. Chỉ xóa các record có CREATE_ID=marker. Không ảnh hưởng record khác.

✏️ 6. Chỉnh thời gian (sửa ATTLOG time)

📋 Hướng dẫn: Dùng khi NV chấm sai giờ. Nhập marker + thời gian mới ISO → bấm Sửa. Lưu ý: backup ZKDB.db trước khi sửa.
