📋 2. Tra log / Đọc chấm công

Hướng dẫn: Chọn số records muốn xem. Tool sẽ đọc từ web backup (nhanh ~5s) hoặc thiết bị (chậm ~25s cho 49k records).
Chưa có dữ liệu. Chọn máy + bấm button trên.

🔐 Test PIN + Password (qua port 4370)

🔐 Kiểm tra user có tồn tại trên máy + so sánh password nếu có. Dùng pyzk get_users() qua port 4370 - nhanh ~3s.
Chưa kiểm tra.

⚡ 3. Chấm công thật (ghi ATTLOG lên máy)

Workflow (4 bước, ~30-60s):
① Tải ZKDB.db từ web backup (auto-fallback: 172.16.254.202 → 172.16.200.105)
② Thêm 1 record ATTLOG mới (PIN + thời gian + marker)
③ Upload ZKDB.db lên máy qua CVE-2023-3941 (~3-4 phút, 32KB chunks)
④ Reboot máy (~30s downtime)
🏷️ Marker (để quản lý records BS đã inject):
• APK_REAL_PUNCH – ghi qua mobile app (workflow thật)
• TEST_INJECT – test/dev thử nghiệm
• BS_CONFIRMED – BS verify thủ công, ATTLOG không thật trên máy nhưng tính như đã chấm
⚠️ Yêu cầu mạng: VPN Bệnh viện bật, có thể truy cập 172.16.x.x. Nếu fail → gọi ý bật VPN.
